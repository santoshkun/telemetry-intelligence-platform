# Telemetry Intelligence Platform

An end-to-end streaming data engineering and MLOps platform for predictive maintenance using real-time telemetry data.

## Project Overview

This project aims to build a scalable telemetry intelligence platform that processes machine sensor data, detects anomalies, and predicts equipment failures before they happen.

It combines real-time data streaming, cloud data warehousing, machine learning, and model monitoring into one integrated pipeline.

## Technology Stack

- **Programming:** Python
- **Dataset:** NASA C-MAPSS
- **Streaming:** Apache Kafka, Apache Spark Structured Streaming
- **Data Warehouse:** Google BigQuery
- **Data Transformation:** dbt
- **Workflow Orchestration:** Apache Airflow
- **Machine Learning:** Scikit-learn, Optuna
- **MLOps:** MLflow
- **API:** FastAPI
- **Containerization:** Docker
- **CI/CD:** GitHub Actions
- **Visualization:** Tableau
